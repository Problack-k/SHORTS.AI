# SHORTS.AI

An Android-accessible, cloud-assisted AI Shorts production studio.

## Pipeline
1. Topic research
2. Hook generation
3. Script development
4. Storyboarding
5. Narration planning
6. Subtitle generation
7. Quality control
8. Video rendering

## Run
python main.py --topic "The mystery of the lost city"

## Current status
Foundation v0.1 — prompt generation only.
